# Leddeo · admin panel

> **Archived (2023).** Part of Leddeo, a SaaS I built and ran in early 2023. No longer maintained.

The internal panel for Leddeo: a dashboard with charts over the job logs the backend records (transcriptions, translations and renders, with their size and duration), and management of the FAQs shown in the app. It talks to [leddeo-backend](https://github.com/carlo-coding/leddeo-backend).

## Stack

React · TypeScript · Vite · Redux Toolkit · Material UI · Chart.js
